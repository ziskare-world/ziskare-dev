# Ziskare.dev

Static homepage recovered from https://ziskare.dev on 2026-11-16.

## Preview
Open index.html in a browser, or run `python3 -m http.server 8080` from this directory.

## Deployment
Publish this directory with any static web host. No build step is required.

## Recovery scope
The public homepage HTML, inline CSS and JavaScript are preserved. The hosting-injected Netlify HUD script was removed because its endpoint is specific to the original host. Google Fonts and Google AdSense remain external network dependencies. No private backend, deployment settings, or original source history is included.
